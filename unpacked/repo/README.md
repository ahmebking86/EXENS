# بوت اقتناص الربح - Sniper Bot

نظام تداول آلي: بوت تليجرام (على Railway) يتحكم بالأزرار في محرك تداول (على EC2 Windows بجانب MetaTrader 5).

⚠️ **يشتغل الأول على حساب MetaTrader تجريبي (Demo) فقط.**

## الفكرة
- المحرك على EC2 بيفتح صفقة باتجاه ثابت (Buy فقط أو Sell فقط حسب اختيارك)، بحجم ووقف خسارة محددين.
- أول ما الربح يوصل للهدف (بالدولار / نسبة / نقاط) → بيقفل الصفقة فوراً.
- يستنى شوية ويفتح صفقة جديدة تاني، وهكذا.
- كل الإعدادات (الاتصال بـ EC2، بيانات MetaTrader، حجم الصفقة، الهدف، الاتجاه...) بتتظبط من جوه بوت التليجرام بالأزرار، ومخزنة في قاعدة بيانات Railway - مش متغيرات بيئة.

## هيكل المشروع
```
telegram-bot/   -> ينشر على Railway (بوت التليجرام + قاعدة البيانات)
ec2-engine/     -> يترفع على سيرفر EC2 Windows (المحرك اللي بيتكلم مع MT5 فعلياً)
```

## خطوات النشر

### 1) EC2 (المحرك)
اتبع التعليمات في `ec2-engine/SETUP_WINDOWS.md`. لما يخلص، هيكون شغال على:
`http://<Elastic-IP>:8443`

### 2) Railway (البوت)
1. اعمل مستودع GitHub وارفع فيه محتوى `telegram-bot/` (أو المشروع كله).
2. على Railway: New Project → Deploy from GitHub → اختار المستودع.
3. ضيف **PostgreSQL plugin** من Railway (هيدي `DATABASE_URL` تلقائي).
4. في Variables ضيف بس:
   - `TELEGRAM_BOT_TOKEN`
   - `ADMIN_TELEGRAM_ID` (آيدي التليجرام بتاعك، تقدر تجيبه من بوت زي @userinfobot)
5. Deploy.

### 3) من داخل تليجرام
- ابعت `/start` للبوت.
- ادخل "🔌 اتصال EC2" وسجّل عنوان EC2 والـ Port والمفتاح السري.
- ادخل "✅ اختبار الاتصال" للتأكد.
- ادخل "🔑 بيانات MetaTrader" وسجّل رقم الحساب التجريبي، الباسورد، اسم السيرفر (زي `Exness-MT5Trial`).
- ادخل "⚙️ إعدادات الاستراتيجية" واظبط الرمز، الحجم، الاتجاه، هدف الربح، وقف الخسارة.
- ارجع للقائمة الرئيسية واضغط "▶️ ابدأ".
- تابع بـ "📊 الحالة" في أي وقت.

## ملاحظات مهمة
- ده مشروع بداية (MVP) لغرض التجربة على حساب Demo. قبل أي تفكير في حساب حقيقي، لازم:
  - تضيف HTTPS على اتصال EC2 (بدل HTTP العادي).
  - تراجع منطق حساب وقف الخسارة (`compute_sl_price`) كويس لأنه تقريبي حالياً.
  - تضيف حماية إضافية (حد أقصى لعدد الصفقات في اليوم، حد أقصى للخسارة اليومية).
- الاستراتيجية بسيطة (اتجاه ثابت + قفل عند أي ربح) - مفيش فيها تحليل فني أو مؤشرات، وده حسب اختيارك.
